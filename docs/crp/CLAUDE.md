# CRP grant work — session anchor

You are working on Olera's NIH SBIR Commercialization Readiness Pilot application.

**Before acting: read `README.md` in this directory** — the operating map (canonical
files, settled decisions, house style, page limits, go/no-go framework).

**Before drafting any section: read `CANON.md`** — the conceptual canon produced by the
40-slide figure sequence. Section 2 is the working foundation (problem narrative,
workforce strategy, beachhead product, payer evidence, human-subjects boundary, Aim
architecture, market design), section 3 is the settled vocabulary, section 4 is what
team feedback may still move, section 5 is what must not be stated as settled, and
section 6 indexes what it supersedes in the older files.

**When Logan says "next paragraph," "let's work on X," or anything like it: run the
paragraph loop in `DRAFTING.md`.** That workflow is ratified and is the default; do
not improvise a different process because progress feels fast.

Hard invariants that survive even a rushed session:

1. **Truthfulness**: never infer that a feature, metric, workflow, or dataset exists
   because it would strengthen the proposal. Distinguish live / in development /
   proposed CRP work. When sources don't settle it, ask Logan.
2. **No em dashes**, anywhere, ever. En dashes only in numeric ranges.
3. **Citations only after verification** against the specific claim, via stable keys
   in `references.yaml`. Never hand-number references. `[@todo: ...]` marks
   unverified claims; the document is not submission-ready while any remain.
4. **Removals are logged** with future homes (`passes/removed-material-log.md`).
   Nothing of the team's work disappears silently.
5. **Render and look** (`tools/render_pdf.py`) before showing Logan a result;
   respect the page budget (RS 12 / CP 12 / Aims 1).

Authority when sources conflict: CRP solicitation and SF424 instructions
(`solicitation-reviewer-reference.md`) → actual Olera evidence, code, and data →
approved application architecture and fixed terminology (README) → external
literature → our hypotheses and projections. Polished prose, older drafts, and
convenient assumptions never override the governing instructions or the evidence.
